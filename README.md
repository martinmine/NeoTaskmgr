# NeoTaskmgr

A modern C# / WinUI 3 re-implementation of Windows Task Manager. See [docs/PLAN.md](docs/PLAN.md) for scope, architecture and milestones.

## Requirements

- Windows 11
- .NET 10 SDK
- Visual Studio 2026 with the "WinUI application development" workload (optional – everything also builds with the `dotnet` CLI)

## Build, test and run

```powershell
dotnet build NeoTaskmgr.slnx -p:Platform=x64
dotnet test --solution NeoTaskmgr.slnx -p:Platform=x64
dotnet run --project src/NeoTaskmgr -p:Platform=x64
```

Use `-p:Platform=ARM64` on ARM devices. The app is unpackaged and, like Task Manager, asks for administrator rights
when the user is an administrator. To test the non-elevated experience, set the environment variable
`__COMPAT_LAYER=RunAsInvoker` before launching.

## Repository layout

| Path | Contents |
|---|---|
| `src/NeoTaskmgr` | WinUI 3 app: shell, pages, view models, controls |
| `src/NeoTaskmgr.Core` | Data collection and actions, no UI dependency. Win32 APIs are generated by CsWin32 from `NativeMethods.txt` |
| `tests/NeoTaskmgr.Core.Tests` | xUnit tests for Core |

NuGet package versions are managed centrally in `Directory.Packages.props`; new packages must be approved first (see the plan).
